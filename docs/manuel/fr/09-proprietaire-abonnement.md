# Espace propriétaire, abonnement et licence

## Espace propriétaire (application Android)

Avec le compte Eden Dev de la boutique (e-mail et mot de passe), sur n'importe quel téléphone :

- **Mes boutiques** : chaque boutique, son **serveur allumé ou éteint**, sa formule et sa date de fin. La liste reste lisible sans Internet.
- **Ouvrir** une boutique à distance : l'écran de l'application s'ouvre, seules les données passent par Internet. Connectez-vous ensuite avec votre identifiant et votre code PIN. « Changer de boutique » revient à la liste.
- **Abonnements** : les derniers paiements, l'activation par **carte de bon**, le paiement **Orange Money** ou **Moov Money** (référence reçue par SMS).
- **Contact Eden Dev** : WhatsApp, appel, e-mail.

La connexion reste ouverte sur le téléphone ; « Se déconnecter » l'efface.

## Mot de passe du compte

- **Oublié** : « Mot de passe oublié ? » (Espace propriétaire, Abonnement & licence, ou « Code PIN administrateur oublié »). Tapez l'e-mail du compte : un **code** y est envoyé. Tapez ce code et le nouveau mot de passe.
- **Changer** : Espace propriétaire → « Mot de passe », ou Abonnement & licence → « Changer le mot de passe du compte ». Le mot de passe actuel est demandé.
- Un bon mot de passe a **8 caractères au moins, avec des lettres et des chiffres**. 12345678, « azerty123 » ou le nom de la boutique sont refusés : ce compte ouvre la boutique à distance et paie l'abonnement.

## Abonnement et licence (PC de la boutique)

Abonnement & licence montre la formule, la date de fin et les postes utilisés. Pour prolonger :

- **Carte de bon** : code imprimé sur la carte achetée chez un revendeur, l'abonnement est activé tout de suite ;
- **Orange Money** : payez au code marchand, puis saisissez la référence reçue par SMS ; Eden Dev valide ;
- **Carte Visa** : page de paiement sécurisée.

Sans compte, la boutique fonctionne **14 jours en essai gratuit** (formule PRO, 3 postes) : Abonnement & licence montre les jours restants et propose de créer le compte.

La licence est vérifiée **sans Internet** sur le poste. Rappels 7, 3 et 1 jours avant la fin ; après la fin, GestiMarket passe en **lecture seule** : les données restent consultables, les ventes sont bloquées.
