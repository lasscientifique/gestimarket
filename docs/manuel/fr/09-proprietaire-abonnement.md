# Espace propriétaire, abonnement et licence

## Espace propriétaire (application Android)

Avec le compte Eden Dev de la boutique (e-mail et mot de passe), sur n'importe quel téléphone :

- **Mes boutiques** : chaque boutique, son **serveur allumé ou éteint**, sa formule et sa date de fin. La liste reste lisible sans Internet.
- **Ouvrir** une boutique à distance : l'écran de l'application s'ouvre, seules les données passent par Internet. Connectez-vous ensuite avec votre identifiant et votre code PIN. « Changer de boutique » revient à la liste.
- **Abonnements** : les derniers paiements, l'activation par **carte de bon**, le paiement **Orange Money** ou **Moov Money** (référence reçue par SMS).
- **Informations** (sous chaque boutique) : nom complet de la propriétaire, **téléphone**, ville et adresse, enregistrés chez Eden Dev. Le nom de la boutique, le pays et le type ne changent pas : demandez à Eden Dev.
- **Contact Eden Dev** : WhatsApp, appel, e-mail.

La connexion reste ouverte sur le téléphone ; « Se déconnecter » l'efface.

## Compte de la boutique : WhatsApp, e-mail, mot de passe

- **Avec un numéro WhatsApp** (quand Eden Dev l'a ouvert) : à la création du compte, choisissez « Avec mon numéro WhatsApp ». L'indicatif vient du pays de la boutique (+223 pour le Mali) ; tapez le numéro tel quel (76 59 36 76). Un **code à 6 chiffres arrive sur WhatsApp** : tapez-le pour terminer. Le compte a aussi un mot de passe. Si GestiMarket le demande, touchez d'abord « **Écrire à GestiMarket** » : WhatsApp s'ouvre avec le message « GestiMarket » prêt, envoyez-le, puis demandez le code (il vous est répondu sur WhatsApp).
- **Se connecter par WhatsApp** : tapez le numéro du compte, puis « **Recevoir un code sur WhatsApp** » : le code remplace le mot de passe. Partout où le compte est demandé (PC, Espace propriétaire, autoriser un téléphone, PIN administrateur oublié), l'e-mail ou le numéro WhatsApp conviennent.
- **Ajouter un numéro WhatsApp** à un compte créé avec un e-mail : Espace propriétaire → « Mon compte » → WhatsApp « Ajouter », ou Abonnement & licence → « Numéro WhatsApp du compte ». Le mot de passe est demandé, puis le code reçu sur WhatsApp. Le compte s'ouvre ensuite avec l'e-mail ou avec le numéro.
- **Confirmer l'adresse** : à la création d'un compte avec un e-mail, un **code à 6 chiffres** est envoyé à l'adresse. Tapez-le pour terminer : la boutique est créée à ce moment-là. Pas reçu ? Regardez les courriers indésirables, puis « Renvoyer le code ». Si la fenêtre a été fermée, le code est demandé à la connexion suivante.
- **Changer l'e-mail** : Espace propriétaire → « Mon compte » → « Changer l'e-mail du compte », ou Abonnement & licence → « Changer l'e-mail du compte ». Tapez le mot de passe et la nouvelle adresse, puis le **code** reçu à la nouvelle adresse. C'est aussi la solution si l'adresse a été mal tapée à l'inscription.
- **Mot de passe oublié** : « Mot de passe oublié ? » (Espace propriétaire, Abonnement & licence, ou « Code PIN administrateur oublié »). Tapez l'e-mail ou le numéro WhatsApp du compte : un **code** est envoyé par e-mail ou sur WhatsApp. Tapez ce code et le nouveau mot de passe.
- **Changer le mot de passe** : Espace propriétaire → « Mon compte » → « Changer le mot de passe », ou Abonnement & licence → « Changer le mot de passe du compte ». Le mot de passe actuel est demandé.
- Un bon mot de passe a **8 caractères au moins, avec des lettres et des chiffres**. 12345678, « azerty123 » ou le nom de la boutique sont refusés : ce compte ouvre la boutique à distance et paie l'abonnement.
- Sur le PC, **Abonnement & licence → « Informations de la boutique »** modifie aussi le téléphone et l'adresse (le mot de passe du compte est demandé).

## Abonnement et licence (PC de la boutique)

Abonnement & licence montre la formule, la date de fin et les postes utilisés. Pour prolonger :

- **Carte de bon** : code imprimé sur la carte achetée chez un revendeur, l'abonnement est activé tout de suite ;
- **Orange Money** : payez au code marchand, puis saisissez la référence reçue par SMS ; Eden Dev valide ;
- **Carte Visa** : page de paiement sécurisée.

Sans compte, la boutique fonctionne **14 jours en essai gratuit** (formule PRO, 3 postes) : Abonnement & licence montre les jours restants et propose de créer le compte.

La licence est vérifiée **sans Internet** sur le poste. Rappels 7, 3 et 1 jours avant la fin ; après la fin, GestiMarket passe en **lecture seule** : les données restent consultables, les ventes sont bloquées.
