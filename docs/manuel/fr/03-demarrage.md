# Premier démarrage

## Sur un téléphone ou une tablette : quatre choix

À la première ouverture, l'application demande comment l'appareil va servir :

- **Ma boutique sur ce téléphone** : toute la boutique est sur ce téléphone, sans ordinateur, même sans Internet. La TV et d'autres caisses pourront s'y relier plus tard.
- **Rejoindre une boutique** : une caisse de plus. Le téléphone cherche tout seul les boutiques sur le Wi-Fi ou le partage de connexion ; touchez la vôtre. Vous pouvez aussi scanner le QR code du serveur ou taper son adresse.
- **Espace propriétaire** : vos boutiques à distance, avec votre compte Eden Dev (voir le chapitre « Espace propriétaire »).
- **J'ai une sauvegarde** : téléphone changé, cassé ou réinitialisé. Choisissez le fichier de sauvegarde (Google Drive, WhatsApp, carte SD…) : la boutique revient telle qu'elle était au moment de la copie, avec ses codes PIN.

Sur un PC neuf, le premier écran propose aussi **« Restaurer la sauvegarde »**.

## Créer la boutique (PC ou « Ma boutique sur ce téléphone »)

0. **Conditions d'utilisation** : lisez les conditions générales d'utilisation, le contrat de licence et la politique de données personnelles, puis acceptez-les au nom de la boutique (voir le chapitre « Conditions d'utilisation, licence et aide »).
1. **Compte de la boutique chez Eden Dev** : e-mail, mot de passe, nom de la boutique, propriétaire, pays, ville, type de commerce. Internet est nécessaire pour cette étape seulement. Sans Internet, « Continuer sans compte » : **14 jours d'essai gratuit** avec toutes les fonctions de la formule PRO. Créez le compte dès que vous avez Internet (Abonnement & licence) ; après 14 jours sans compte, GestiMarket passe en lecture seule. L'essai n'a lieu qu'une fois par boutique.
2. **La boutique** : devise, adresse, téléphone.
3. **L'équipe** : chaque personne a un **identifiant** et un **code PIN** (pas de mot de passe). Des codes sont proposés au hasard : notez-les ou changez-les. Un administrateur, un gestionnaire et une caissière sont créés par défaut.

## Se connecter

À l'écran de connexion, touchez votre nom, puis tapez votre code PIN. Le code PIN sert aussi à **confirmer les actions sensibles** (remise importante, annulation, retour, modification des paramètres) : l'action est notée à votre nom dans le journal d'activité.

Code PIN de l'administrateur oublié : « Code PIN administrateur oublié ? » sur l'écran de connexion, avec l'e-mail et le mot de passe du compte de la boutique.

## Les rôles

| Rôle | Peut |
|---|---|
| **Administrateur** | Tout : paramètres, personnel, rapports, abonnement |
| **Gestionnaire** | Produits, stock, achats, plan, clients, valider les remises et les retours |
| **Caissier** | Caisse, ses ventes, clients, retours (selon les réglages) |
