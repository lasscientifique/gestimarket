# Installer GestiMarket

## Sur un PC Windows

1. Téléchargez **GestiMarket_x.y.z_x64-setup.exe** (fourni par Eden Dev ou sur la page des versions).
2. Double-cliquez dessus. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.
3. GestiMarket s'installe pour l'utilisateur du PC, sans droits d'administrateur, et s'ouvre.

**Version portable** : le fichier **GestiMarket_x.y.z_portable_windows.zip** contient `gestimarket.exe`, qui se lance sans installation (clé USB, PC sans droits).

**Mise à jour** : installez simplement la nouvelle version par-dessus. Les données sont gardées. L'administrateur voit un bandeau « GestiMarket x.y.z est disponible » quand une nouvelle version sort.

## Sur un téléphone, une tablette ou une TV Android

1. Copiez le fichier **GestiMarket_x.y.z_android.apk** sur l'appareil (câble, WhatsApp, clé USB pour une TV).
2. Ouvrez-le. Android demande d'**autoriser l'installation d'applications de cette source** : acceptez pour le gestionnaire de fichiers ou WhatsApp.
3. Touchez **Installer**, puis **Ouvrir**.

Sur une TV Android, GestiMarket apparaît ensuite sur l'écran d'accueil de la TV.

## Sur un iPhone ou un iPad

Il n'y a pas encore d'application iPhone. L'iPhone se relie au serveur de la boutique avec **Safari** :

1. Sur le serveur de la boutique (PC ou téléphone), ouvrez **Poste & réseau** : un QR code s'affiche.
2. Sur l'iPhone, scannez ce QR code avec l'**appareil photo** : GestiMarket s'ouvre dans Safari.
3. Touchez le bouton **Partager**, puis **Sur l'écran d'accueil** : une icône GestiMarket est créée.

## Ancien téléphone ou boîtier TV

GestiMarket marche avec Android 7 et plus récent, si le moteur web du téléphone est à jour. Si l'écran « GestiMarket n'arrive pas à démarrer » s'affiche, ouvrez le **Play Store** et mettez à jour **Android System WebView** et **Google Chrome**, puis relancez GestiMarket.
