# Security, backups and help

## Backups

- **Automatic copy every day** (Settings → Backup). On a PC, choose a folder on a USB stick, an external drive or a synced folder (Google Drive, OneDrive).
- **Copy on demand**: “Copy to a USB stick…” (PC) or “Save a copy…” (phone).
- An alert appears if no backup has succeeded for 48 hours.

## Security

- Each important action is recorded in the **activity log** (who, what, when).
- **PIN codes** confirm discounts, cancellations, returns and settings changes.
- Phones connecting **from the Internet** must be authorised by the administrator.
- Program failures are sent to Eden Dev to be fixed, **without any business data** (can be turned off in Settings → Security).

## Built-in help

- Each screen's **Help** button explains the screen step by step, with its **videos**.
- The small **?** buttons explain each feature; “Watch the video” shows it in action.
- **Offline help** (Settings → Eden Dev developer): download the videos and this manual once (about 100 MB). They then work without Internet, and the server serves them to the shop's phones.

# Frequently asked questions

**The till says “Server unreachable”.** The server PC or phone is off, or the device is no longer on the same Wi-Fi or hotspot. Turn the server back on, check the Wi-Fi, then try again: a sale already recorded is never counted twice.

**The TV does not find the shop.** The TV and the server must be on the same Wi-Fi or hotspot, and the server must be in “Shop server” mode. Tap “Search” on the TV.

**The phone server stops when the screen turns off.** Allow GestiMarket to run in the background (banner or Station & network), and keep the phone plugged in.

**“Read-only” is shown.** The subscription has ended: extend it (Subscription & licence or Owner space). The data is never lost.

**I forgot my PIN.** An administrator resets it in Staff. Forgotten administrator PIN: sign-in screen, with the shop account.

**The stock is wrong.** Stock & inventory → adjust the product (reason: inventory). The log shows each movement and its author.

**GestiMarket cannot start on an old phone.** Update “Android System WebView” and “Google Chrome” in the Play Store.

**Changing a device's role.** Station & network: single station, shop server or client station, then “Save and restart”.
