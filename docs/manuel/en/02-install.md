# Installing GestiMarket

## On a Windows PC

1. Download **GestiMarket_x.y.z_x64-setup.exe** (provided by Eden Dev or on the releases page).
2. Double-click it. If Windows shows “Windows protected your PC”, click **More info**, then **Run anyway**.
3. GestiMarket installs for the PC user, without administrator rights, and opens.

**Portable version**: **GestiMarket_x.y.z_portable_windows.zip** contains `gestimarket.exe`, which runs without installation (USB stick, PC without rights).

**Update**: simply install the new version over the old one. Data is kept. The administrator sees a “GestiMarket x.y.z is available” banner when a new version is released.

## On an Android phone, tablet or TV

1. Copy **GestiMarket_x.y.z_android.apk** to the device (cable, WhatsApp, USB stick for a TV).
2. Open it. Android asks to **allow installing apps from this source**: accept for the file manager or WhatsApp.
3. Tap **Install**, then **Open**.

On an Android TV, GestiMarket then appears on the TV home screen.

## On an iPhone or iPad

There is no iPhone app yet. The iPhone connects to the shop server with **Safari**:

1. On the shop server (PC or phone), open **Station & network**: a QR code is shown.
2. On the iPhone, scan the QR code with the **Camera**: GestiMarket opens in Safari.
3. Tap **Share**, then **Add to Home Screen**: a GestiMarket icon is created.

## Old phone or TV box

GestiMarket works with Android 7 and later, if the phone's web engine is up to date. If the “GestiMarket cannot start” screen appears, open the **Play Store**, update **Android System WebView** and **Google Chrome**, then restart GestiMarket.
